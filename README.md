# F.A.B CO LTD: online store prototype

A clickable prototype of the F.A.B CO LTD online store for aluminum profiles, sheets and accessories.

- `index.html`: the customer store (home, categories, search, product page with variants, cart, sign-in, wholesale application, checkout, my orders)
- `admin.html`: the admin panel (wholesale account approvals, product management, orders)

## Try it

- Sign in with any email and password to see wholesale prices.
- Open the admin panel from the link in the footer.

All products, prices, customers and orders are sample data. Nothing is saved, so refreshing a page resets the demo.

## Run it locally

Open `index.html` in a browser.

## Built with

HTML, CSS and [Alpine.js](https://alpinejs.dev) (bundled in `js/alpine.min.js`).
